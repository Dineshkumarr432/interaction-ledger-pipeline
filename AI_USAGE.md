# AI usage disclosure

AI assistance was used to help structure the implementation, draft documentation, and review edge cases in the assignment specification. The generated code was then run locally against the supplied synthetic data generator, and the included unit tests and end-to-end smoke test were executed.

The final implementation and its behavior should be reviewed by the submitter before delivery. In particular, the submitter should be prepared to explain the HMAC-based phone lookup, authenticated encryption, orphan re-linking, idempotency fingerprints, and effective-disposition/bucket calculations.
